# ⛏️ Miner Wars Toolkit

A comprehensive toolkit for GoMining's Miner Wars game. Track blocks, predict round lengths, calculate ROI, and coordinate with your clan!

## 🚀 Live Demo

**[Open the Toolkit](https://PsyStew1.github.io/miner-wars-toolkit/)**

## ✨ Features

### ⏱️ Block Timer
- Live Bitcoin block tracking via mempool.space API
- - Time since last block with visual progress bar
  - - Sound alerts for new blocks and long rounds
   
    - ### 🔮 Block Predictor
    - - Analyzes last 20 blocks to predict round length
      - - Short/Normal/Long probability percentages
        - - Visual history chart
         
          - ### 💰 Price Tracker
          - - Live GOMINING and Bitcoin prices
            - - Price alerts with notifications
             
              - ### 📊 ROI Calculator
              - - Expected value calculations
                - - Multiplier selection (x1 to x256)
                 
                  - ### 📒 Spending Tracker
                  - - Log spent/earned tokens
                    - - Weekly statistics
                     
                      - ### ⚔️ Clan Comparison
                      - - Compare multiple clans
                       
                        - ### 🤖 Discord Bot
                        - - Coordinated boost sessions
                          - - Block alerts
